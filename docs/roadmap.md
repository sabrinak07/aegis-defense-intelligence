# Aegis Roadmap

Aegis is designed in stages, starting with a focused v1 MVP and growing into a stronger geopolitical monitoring workflow.

## Aegis v1: Student MVP

Aegis v1 proves the core idea.

### Included in v1

- Public SIPRI and World Bank military-spending data
- Foundry transforms
- `country_risk_curated` dataset
- `country_alerts_final` dataset
- `Alert` ontology object
- Workshop app with filters
- Alert list / alert queue
- Alert details panel

### Purpose

The purpose of v1 is to show that public defense-spending data can be transformed into structured, ontology-backed alert records for analyst review.

---

## Aegis v2: Stronger Analyst Workflow

Aegis v2 would make the app feel more operational and polished.

### Planned v2 Improvements

- Better alert queue display
- Improved priority and status handling
- Stronger trend visualizations
- Review or escalation actions
- More meaningful filtering
- Cleaner visual layout
- Better explanation of alert logic

### Purpose

The purpose of v2 is to make Aegis more useful for a real analyst workflow.

---

## Future Version: Geopolitical Watchfloor

A future version of Aegis could expand beyond defense-spending alerts into a broader monitoring platform.

### Future Ideas

- Add defense procurement and contract data
- Add map-based geopolitical views
- Add regional risk summaries
- Add AI-generated alert explanations
- Add analyst notes
- Add alert review history
- Add forecasting or anomaly detection
- Support multiple object types beyond Alert

### Long-Term Vision

The long-term vision for Aegis is a geopolitical watchfloor that combines public data, ontology-backed objects, and analyst workflows to help users move from raw data to prioritized monitoring and action.
